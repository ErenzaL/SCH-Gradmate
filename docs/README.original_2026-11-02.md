# 순천향대학교 AI·빅데이터학과 졸업 도우미

한국어 Streamlit 챗봇입니다. PDF, TXT, Markdown 자료를 페이지와 출처를 보존해 읽고, 표는 PyMuPDF 표 추출을 우선 사용합니다. 문서 청크에는 자료명, 쪽수, 분야, 자료가 명시하는 학번 정보가 포함됩니다. 학번을 특정하지 않은 공통 자료는 모든 학번 검색에 남습니다.

검색은 한국어를 지원하는 `paraphrase-multilingual-MiniLM-L12-v2` 임베딩과 FAISS 의미 검색, BM25 키워드 검색을 결합합니다. 로컬 모델 캐시를 사용하며, 색인 벡터와 문서 메타데이터는 `data/processed/rag_index/`에 저장합니다. 자료가 바뀌면 내용 지문을 비교해 색인을 다시 생성합니다.

## 실행

Python 3.11 또는 3.12와 프로젝트 가상환경을 사용합니다.

```bash
source .venv/bin/activate
pip install -r requirements.txt
streamlit run app.py
```

## 수강과목 분석

채팅에서 **수강과목 분석하기**를 선택하고 CSV 또는 XLSX 성적표를 올립니다. CSV 양식은 **예시 양식 받기**에서 내려받을 수 있습니다. 필수 열은 `course_name,credits,category,status`이며, `course_code`는 선택 항목입니다. `status`에는 `completed` 또는 `in_progress`를 사용합니다. 한국어 열 이름과 `완료`, `수강중` 상태도 읽을 수 있습니다. 파일은 메모리에서만 처리하며 기본 설정에서는 디스크에 저장하지 않습니다.

과목명은 유니코드와 띄어쓰기를 정리해 대조하며, 중복 가능 과목은 두 번 계산하지 않고 수강 중 과목은 완료 학점 합계에서 뺍니다. 분류가 명확하지 않은 학점은 총 이수학점에는 포함하되 전공·교양 점수로 임의 분류하지 않습니다. 과목명이나 구분이 잘못 읽힌 경우 채팅 안의 편집 표에서 바로잡을 수 있습니다. 공식 교육과정에 대조할 검증된 과목 코드·별칭 목록이 없으면 과목명 일치나 전공필수 이수 여부를 자동 확정하지 않습니다.

학번별 규정은 `data/graduation_rules.json`을 사용합니다. 현재 문서에서 확인된 2024학번 기준은 총 130학점, 전공 76학점, 교양 32학점이며, 전공기초 28학점·전공선택 48학점·교양공통 12학점·교양영역 9학점·교양선택 11학점 기준도 기록되어 있습니다. 학생 파일의 분류가 이 세부 구분과 일치하지 않으면 세부 판정은 **확인 필요**로 표시합니다. 2019~2021학번(80점), 2022학번(95점), 2023~2026학번(95점)은 다면적 졸업인증 점수 소계만 확인되어 있습니다. 이 학번들의 총·전공·교양 학점 기준은 제공 자료에서 확인되지 않아 계산하지 않습니다.

현재 공식 과목별 전공필수 목록, 검증된 과목 별칭, 봉사학습 및 기타 학과 요건을 대조할 충분한 기계 판독 자료가 없습니다. 해당 항목은 자동 판정하지 않고 **확인 필요**로 안내합니다. 점수 활동은 학생 입력에 따른 참고 추정치이며 증빙 승인 여부를 뜻하지 않습니다. 어떤 결과도 공식 졸업 승인으로 간주하지 마세요.

## 비교과 활동 점검

채팅에서 **비교과 활동 체크하기**를 선택하고 학번을 지정하면, `data/graduation_rules.json`에 해당 학번용으로 확인된 활동만 표시합니다. 현재 2023~2026학번 자료의 배점만 입력되어 있습니다. 반복 실적 횟수는 문서에 적힌 상한까지만 예상 점수로 계산하며, TOPCIT처럼 일회성인 항목은 한 번만 반영합니다. 공식 승인 점수 입력란은 학생 보고값으로 따로 보관하고 예상 점수에 합산하지 않습니다.

예상 점수만으로 비교과 졸업인증을 **충족**으로 확정하지 않습니다. 목표 점수보다 낮으면 미충족, 목표를 넘더라도 증빙과 공식 승인 확인 전에는 확인 필요로 안내합니다. 2019~2022학번 활동별 배점, 필수 활동·카테고리, 외국인 유학생 봉사학습 면제 및 승인 증빙 기준은 현재 자료에서 확인되지 않아 추정하지 않습니다. 수강과목 파일과 활동 입력은 통합 졸업요건 점검에서 함께 참고합니다.

Gemini 답변 생성은 선택 항목입니다. 로컬에서는 `.env`의 `GEMINI_API_KEY`와 `GEMINI_MODEL`, Streamlit Community Cloud에서는 앱의 Secrets에 같은 키를 설정합니다. 키나 모델이 없거나 API를 사용할 수 없으면 검색 기반 기능은 유지되며 자격 증명은 서버 측에서만 읽습니다.

## 자료 처리 한계

이미지와 스캔 페이지에는 OCR을 적용하지 않습니다. 해당 파일이나 페이지는 인식이 필요하다는 안내를 색인 결과와 함께 표시하며, 인식되지 않은 내용은 답변 근거로 만들지 않습니다. 현재 제공 자료 중 AI빅데이터학과 교육과정 PDF 1~2쪽과 이미지 기반 졸업요건 자료는 텍스트 검색이 불가합니다. 확인 가능한 2024학번 요건 요약은 자료 원본 및 쪽수와 함께 검색에 포함했습니다.

## Jupyter 실습 노트북

실습 노트북은 Streamlit과 같은 `src/` 문서 처리·검색·답변 함수를 사용합니다. `.venv` 커널을 등록한 뒤 VS Code 또는 JupyterLab에서 `notebooks/SCH_Graduation_RAG.ipynb`를 엽니다.

```bash
source .venv/bin/activate
python -m ipykernel install --user --name sch-gradmate-venv --display-name 'SCH GradMate (.venv)'
jupyter lab
```

VS Code에서는 노트북 커널로 **SCH GradMate (.venv)** 를 선택합니다. Gemini 답변 생성을 사용하려면 `.env`에 키와 Google AI Studio에서 사용 가능한 모델 이름을 지정합니다. 모델 이름을 코드에 고정하지 않습니다.

```dotenv
GEMINI_API_KEY=발급받은_키
GEMINI_MODEL=사용_가능한_모델_ID
```

키 또는 모델 설정이 없으면 노트북은 검색 및 평가 셀을 계속 실행하고, Gemini 생성 셀은 한국어 안내와 함께 건너뜁니다. Gemini 서비스 오류가 발생해도 검색 기반 한국어 답변으로 대체합니다.

노트북은 19개 장으로 구성되어 있으며, 30개 평가 질문의 실제 검색 결과를 다음 파일에 저장합니다.

- `data/evaluation/questions.json`: 기대 사실·학번·문서/쪽·실제 청크 ID
- `data/evaluation/results/retrieval_metrics.csv`: 질의별 검색 지표 및 지연시간
- `data/evaluation/results/answer_evaluation.csv`: 제한된 자동 인용·미지원 처리 검사

노트북을 다시 실행하려면 프로젝트 루트에서 `.venv`를 활성화하고 Jupyter에서 **Run All**을 선택합니다. CLI로 실행할 때는 다음 명령을 사용합니다.

```bash
.venv/bin/jupyter nbconvert --to notebook --execute --inplace notebooks/SCH_Graduation_RAG.ipynb --ExecutePreprocessor.timeout=600 --ExecutePreprocessor.kernel_name=sch-gradmate-venv
```

공개 배포는 아직 완료되지 않았습니다. Streamlit Community Cloud 등 공개 호스팅을 선택할 경우 `.env`를 업로드하지 말고 호스팅 서비스의 비밀 환경변수 설정을 사용해야 합니다. 이 저장소에는 검증된 공개 앱 URL이 없습니다.

Community Cloud 준비 순서: 저장소를 연결하고 앱 진입 파일로 `app.py`를 지정한 뒤, Secrets에 다음을 추가하고 배포합니다. 첫 실행은 임베딩 모델 내려받기와 문서 색인 생성으로 시간이 더 걸릴 수 있습니다. `data/processed/rag_index/`는 재생성 가능한 캐시이며 플랫폼 재시작 후 유지된다고 가정하지 않습니다.

```toml
GEMINI_API_KEY = "발급받은 키"
GEMINI_MODEL = "사용 가능한 모델 ID"
```
