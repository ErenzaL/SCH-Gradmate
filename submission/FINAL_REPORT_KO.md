# SCH Graduation RAG 프로젝트 제출 보고서

## 프로젝트 및 연구 질문

순천향대학교 AI·빅데이터학과 졸업자료에서 근거를 찾아 한국어로 설명하는 RAG 챗봇을 구현했습니다. 연구 질문은 “검색 기법의 개선이 한국어 대학 졸업요건 질의응답의 정확도에 어떤 영향을 미치는가?”입니다. 학점·비교과 점수 계산은 Gemini가 아닌 Python 규칙 엔진에서 수행합니다.

## 데이터와 방법

대학 문서 8개를 처리 대상으로 확인했습니다. 텍스트 추출 결과는 60개 청크이며, 스캔 또는 이미지 페이지 6건은 OCR이 필요하다고 표시됩니다. 모델은 `paraphrase-multilingual-MiniLM-L12-v2`(384차원), 키워드 검색은 한국어 토큰·2-그램 BM25를 사용합니다. 하이브리드는 정규화한 BM25(가중치 0.62)와 코사인 점수(0.38)를 결합하고, 재정렬은 하이브리드 0.7·질의 포함률 0.3으로 계산합니다.

## 측정 결과

30개 평가 질문 중 27개가 근거 페이지 라벨을 보유해 검색 평가에 사용됐습니다. 라벨은 문서·쪽 단위이며 모든 관련 구절을 포괄한다고 보장할 수 없습니다.

| 검색 방식 | Recall@5 | MRR@5 | Hit Rate@5 | 평균 지연 |
|---|---:|---:|---:|---:|
| BM25 | 0.870 | 0.846 | 0.889 | 0.2ms |
| FAISS | 0.778 | 0.699 | 0.852 | 14.6ms |
| 하이브리드 | 0.944 | 0.872 | 1.000 | 14.4ms |
| 하이브리드+재정렬 | 0.944 | 0.851 | 1.000 | 14.7ms |

이 평가셋에서 하이브리드는 BM25 대비 Recall@5를 0.074, FAISS 대비 0.167 높였습니다. 재정렬은 Recall@5 향상이 없었고 MRR@5는 0.020 낮아졌습니다. 결과는 이 문서·라벨 집합에 한정됩니다.

답변 자동 점검은 대표 질문 4개를 대상으로 했습니다. Gemini API는 세 지원 가능 질문에서 429 할당량 초과로 생성하지 못했고, 검색 기반 대체 답변을 표시했습니다. 범위 밖 질문은 미지원 안내로 처리했습니다. Gemini 사실성·환각 평가는 생성 응답이 없어 미완료입니다.

## 실행 및 검증

- 노트북: `.venv`의 `SCH GradMate (.venv)` 커널에서 18개 코드 셀 순차 실행, 오류 0개
- 테스트: `pytest` 26개 통과
- Streamlit: 환영 화면·CSV 업로드·후속 질문·비교과 체크 흐름 확인, HTTP 200
- 공개 배포: 미실시, 공개 URL 없음

```bash
python -m pip install -r requirements.txt
jupyter lab SCH_Graduation_RAG.ipynb
streamlit run app.py
```

## 한계와 남은 작업

교육과정·졸업요건 스캔 페이지에는 OCR이 필요합니다. 공식 교과목 필수 목록과 일부 학번별 세부 기준은 확인되지 않아 자동 판정하지 않습니다. 관련성 라벨은 부분적 문서·쪽 판단이며 답변 품질 자동 검사는 인용·학번·언어 proxy입니다. Gemini의 가용 할당량 확보 후 생성 응답을 수작업으로 사실성·근거성 검토해야 합니다. 공개 배포 시 문서 배포 권한과 Secrets 설정도 검토해야 합니다.
